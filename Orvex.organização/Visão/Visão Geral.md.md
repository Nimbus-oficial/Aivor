# O Que é a Orvex

A Orvex é uma plataforma criada para simplificar o acesso à infraestrutura financeira global.

Seu objetivo não é criar novas tecnologias.

Seu objetivo é tornar tecnologias existentes mais acessíveis.

---

# Nossa Tese

O maior problema do mercado financeiro moderno não é a falta de tecnologia.

O maior problema é a falta de acessibilidade.

Nos últimos anos surgiram:

- blockchains
    
- stablecoins
    
- protocolos financeiros
    
- novas infraestruturas
    

Mas para a maioria das pessoas essas oportunidades continuam inacessíveis.

A Orvex existe para reduzir essa distância.

# POSTGRESQL

## Objetivo

Atuar como banco de dados principal da Orvex.

---

## Responsabilidades

Armazenar:

- usuários
    
- perfis
    
- notificações
    
- analytics
    
- configurações
    
- logs
    
- eventos administrativos
    

---

## Não Armazena

- fundos
    
- chaves privadas
    
- ativos financeiros
    

---

## Utilização

O PostgreSQL é utilizado pelo [[Backend]] para persistência de dados operacionais.

---

## Relacionamentos

- [[Banco de Dados]]
    
- [[Backend]]
    
- [[Redis]]
    
- [[Observabilidade]]
    

---

## Filosofia

Persistir apenas dados necessários para o funcionamento da plataforma.

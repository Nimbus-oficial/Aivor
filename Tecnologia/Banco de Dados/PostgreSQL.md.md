# PostgreSQL

## Objetivo

Descrever a utilização do PostgreSQL dentro da Orvex.

Relaciona-se com:

- [[Banco de Dados]]
    
- [[PostgreSQL Schema]]
    
- [[Backend]]
    
- [[Eventos e Auditoria]]
    

---

## Função

O PostgreSQL é o banco de dados principal da Orvex.

Responsável pelo armazenamento persistente das informações operacionais.

---

## Utilização

Armazenamento de:

- usuários
    
- configurações
    
- eventos
    
- auditoria
    
- histórico operacional
    
- permissões administrativas
    

---

## Não Armazena

O PostgreSQL não possui custódia de patrimônio.

Os ativos permanecem registrados na blockchain.

Ver:

[[Smart Contracts]]

---

## Benefícios

- confiabilidade
    
- consistência
    
- escalabilidade
    
- ampla adoção
    

---

## Relação com o Backend

Toda comunicação com o PostgreSQL ocorre através do backend.

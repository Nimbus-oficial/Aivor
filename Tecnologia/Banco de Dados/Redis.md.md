# Redis

## Objetivo

Descrever a utilização do Redis dentro da Orvex.

Relaciona-se com:

- [[Banco de Dados]]
    
- [[Backend]]
    
- [[Observabilidade Técnica]]
    

---

## Função

O Redis atua como camada de desempenho.

---

## Utilização

- cache
    
- sessões
    
- filas
    
- rate limiting
    
- dados temporários
    

---

## Benefícios

- velocidade
    
- redução de carga
    
- melhoria de experiência do usuário
    

---

## Princípios

O Redis não deve ser utilizado como armazenamento permanente de informações críticas.

# O Que é a Aivor

A Aivor é uma plataforma criada para transformar infraestrutura financeira global em uma experiência simples, acessível e moderna.

Sua existência é baseada na tese de que o principal problema do mercado financeiro moderno não é a falta de tecnologia.

É a falta de acessibilidade.

# Filosofia

A Aivor acredita que:

- tecnologia deve reduzir barreiras
    
- experiências importam mais que infraestrutura
    
- simplicidade é uma forma de inovação
    
- acessibilidade gera adoção

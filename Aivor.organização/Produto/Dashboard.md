# Dashboard

## Objetivo

Descrever a experiencia principal de visualizacao do usuario.

## Regras

O dashboard deve exibir:

- saldo em USD;
- rendimento;
- crescimento patrimonial;
- historico;
- status operacional relevante.

O dashboard nao deve expor complexidade tecnica de ERC4626, shares, rebasing ou protocolos internos para o usuario comum.
